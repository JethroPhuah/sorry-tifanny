# sorry-tifanny

Two static pages, no build step.

- `index.html`, `style.css`, `script.js`: the original apology site.
- `japan-trip/index.html`: **Japan Driving Trip September**, three nature day
  trips out of Osaka for 17–19 September 2026 (Lake Biwa and Hirugano, the Nara
  mountains, the Tango coast). Self-contained: generated landscapes, a vector
  route map, and a live Open-Meteo forecast that scores every ordering of the
  three trips over the three dates and offers the driest one. Falls back to an
  embedded forecast snapshot where outside requests are blocked. Web fonts load
  from Google Fonts.

Open either file directly in a browser, or serve the repository root with
GitHub Pages and visit `/japan-trip/`.
