# sorry-tifanny

Two small static pages, no build step.

- `index.html` — the original apology site.
- `japan-trip/index.html` — **Japan Driving Trip September**: a three-day nature road-trip planner built from the saved Google Maps list. Two switchable plans (Northern Alps loop with two nights in Hirayu Onsen, or three Kansai day trips from Higashiyodogawa), an interactive route map, per-stop parking and vegetarian food notes, toll and budget estimates, and cheap automatic car-rental options near Shin-Osaka.

Open either file directly in a browser. The trip page loads its map library and fonts from public CDNs, so it needs an internet connection; if GitHub Pages is enabled for the repo it is served at `/japan-trip/`.
